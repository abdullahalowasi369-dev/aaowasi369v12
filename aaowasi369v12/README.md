# Md. Abdullah Al Owasi — Portfolio v12

Technology Risk · GRC · TPRM · AI Governance

This repository contains the production portfolio and its supporting career assets. The site is deliberately implemented as dependency-free HTML, CSS, SVG and browser JavaScript so the experience does not depend on framework packages, hydration, remote fonts or third-party chart engines.

## Production structure

- `index.html` — complete portfolio application and content
- `assets/styles.css` — stable v11 base visual system
- `assets/app.js` — stable v11 base interactions, filters and theme behavior
- `assets/premium-v12.css` — premium v12 design/animation layer
- `assets/premium-v12.js` — premium v12 cursor, matrix, card-deck and dynamic-island interactions
- `career-assets/` — resume, cover letter, portfolio, presentation and supporting documents
- `artifacts/` — governance evidence matrix and governance evidence workbook
- `scripts/` — dependency-free build, preflight, output verification and local server
- `out/` — deterministic deployment output generated by `npm run build`
- `V12_IMPLEMENTATION_GUIDE.md` — detailed explanation and safe modification guide

## Validation

```bash
npm run check
npm run build
npm start
```

The project has zero npm runtime or build dependencies. `npm run build` uses Node.js standard-library APIs only.

Deployment settings are documented in `DEPLOYMENT.md`.
